# Cobro QR para Eleventa — descargas

Cobro con QR Bre-B en la caja de Eleventa: **Ctrl+Q** muestra el QR con el valor exacto de la venta y, cuando llega el aviso del banco, la venta se cobra sola como Transferencia.

## Instalar en una tienda nueva

1. Descargar la última versión: **[CobroQR.zip](https://github.com/neohack7/cobro-qr/releases/latest/download/CobroQR.zip)**
2. Descomprimirlo en `C:\` (queda `C:\CobroQR`) y seguir `C:\CobroQR\LEEME.md`.

Requiere una licencia por tienda: solicítala a soporte. Las cajas instaladas se actualizan solas.
